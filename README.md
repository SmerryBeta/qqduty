# QQ Duty

Windows 上的 QQ 值守桥。虚拟机里的 QQ 收到消息后，这台电脑上的桥轮询日志，交给本机 Qoder 想一句，再从 OneBot 接口发回群里。

人在外面、电脑在家时，可以在群里让它闲聊、查东西，或者由主人念咒让它在这台电脑上干活。

## 怎么串起来

```
QQ（虚拟机里的 OneBot）
    │  消息追加到 messages.jsonl
    ▼
Windows 桥 qoder_host_bridge.py
    │  拉日志、认 @ 和咒语、调 Qoder CLI
    ▼
OneBot HTTP（默认端口 6700）把回复发回群
```

桥只跑一份。开两个进程，同一条消息会回两遍。改完桥的代码要关掉再开，热重载不会自己生效。

## 第一次怎么用

1. 虚拟机上的 OneBot 已经在线，能把群消息写进 `/opt/bot/nonebot/data/messages.jsonl`，并且开放 HTTP 接口（端口 6700，带 Bearer token）。
2. 本机装好 Python、`paramiko`，以及 Qoder CLI。
3. 复制凭据模板，填上自己的值。这个文件不进 git：

```
copy data\local_secrets.example.json data\local_secrets.json
```

| 字段 | 填什么 |
|---|---|
| `vm_host` | 虚拟机地址 |
| `vm_user` / `vm_password` | SSH 登录 |
| `api_token` | OneBot HTTP 的 Bearer token |
| `self_id` | 机器人自己的 QQ 号 |
| `owner_id` | 主人 QQ 号。念咒干活、解禁、转发只认这个号 |
| `qoder_cmd` | 本机 `qoder.cmd` 的完整路径 |

4. 双击 `start_host_bridge.bat`。日志在 `data/qoder_bridge.log`，看到 `connected, start at offset` 就是连上了。
5. 群默认是封印的，机器人不闲聊。主人先念解禁咒，再 `@` 它说话。

语音要另开本机 GPT-SoVITS（默认 `127.0.0.1:9880`）。音色档案在 `data/voices.json`，可用 `qq_cli.bat` 切换。没开语音时，相关指令会直接说功能没开。

开关在 `data/bot_config.json`：撤回、截屏、路人搜索、语音、追看、群活跃插话、合并转发。缺键用默认值，改完不用重启桥。

## 群里怎么说话

群里要 `@` 机器人才算叫它。私聊视为已 `@`。咒语开头的消息不用 `@`，但后面的任务仍然要 `@`。回复它自己的消息再说「撤回」，不用 `@`。

AI 回复（闲聊、语音、搜索、主人任务的最终汇报）从收到消息算起，至少再过随机 3～5 秒才开口。模型已经想更久就不再加。帮助、反馈、记账、转发、撤回这些指令马上回。

### 所有人

| 说法 | 效果 |
|---|---|
| `@bot` 加任意话 | 闲聊。带图能看，多张会拼成一张。封印中的群不回 |
| `@bot 帮助` | 功能清单，要整句匹配 |
| `@bot 反馈 内容` | 原样记到本机，不走 AI。可带图。封印群也能用 |
| `@bot 记账 内容` | 记一条到自己的记账本 |
| `@bot 记账本`，或只说 `@bot 记账` | 看自己记了什么 |
| `@bot 划掉 序号` | 删掉那一条。`完成 序号` 同样有效 |
| `@bot 语音！内容` | 用当前音色把回复念出来。封印群不说 |
| `@bot` 加 `巴啦啦能量` 或 `古娜拉黑暗之神`，再加任务 | 路人只有联网搜索，不能动这台电脑。同群同时只跑一个 |
| 问某人头像长什么样 | 先去看头像再回答 |

记账每人一本，存在本机 `data/todos.json`，别人看不见。每人最多 30 条，每条 120 字。

`啦` 打成 `拉` 也认。表情类口令如果和别的服务撞车，桥会让开，避免做两遍。

### 主人

主人 QQ 由 `owner_id` 决定。

| 说法 | 效果 |
|---|---|
| `@bot 巴啦啦能量！任务` 或 `@bot 古娜拉黑暗之神！任务` | 完整 agent：能读文件、跑命令。咒尾的 `！` 可有可无 |
| `@bot 古娜拉黑暗之神！语音！任务` | 干完活用语音汇报。路人念这句会降成普通语音聊天 |
| `古娜拉黑暗之神，呜呼啦呼，黑魔变身` | 解禁本群闲聊。不用 `@` |
| `巴啦啦能量，呜卡拉卡，小魔仙，全身变` | 重新封印本群。不用 `@` |
| `巴啦啦能量 op QQ号` | 给这个号撤回和截屏权限。`授权` 同效 |
| `巴啦啦能量 deop QQ号` | 收回。`收权` 同效 |
| `巴啦啦能量 oplist` | 看权限表。`权限表` 同效 |
| 回复一条消息，`@bot 转发到群 群名` | 把那条转到指定群。回复的是机器人自己连发的消息时，整段一起带走，到别人插话为止，最多 6 条 |
| `@bot 发给群 群名：内容` | 把冒号后面的内容发到那个群。群名可以是全名、模糊名或群号 |
| `@bot 截屏` | 截这台电脑的屏幕发到群里 |

任务跑着的时候，主人再 `@bot` 加同一句咒语和补充说明，不会另开任务，而是写进这个群的收件箱，当前任务下一步会读到。

OP 只有撤回和截屏，没有 agent。

### 撤回

回复机器人的某条消息，只说「撤回」。主人或 OP 可以撤，而且只能撤机器人自己发的，还受 QQ 大约 2 分钟的限制。撤别人的消息时它不插嘴。

## 更新

### 2026-11-12

- 记账本：每人一个 key，记、看、划掉都是纯代码，封印群也能用。
- AI 回复加了 3～5 秒的最低思考时间。指令不垫这个时间。
- 虚拟机密码、接口 token、QQ 号、Qoder 路径改到本机 `data/local_secrets.json`，公开仓库里不再写这些。

### 2026-11-11

- `@bot` 一条合并转发，或引用一条合并转发再 `@bot`，会把里面的文字和图片展开给模型。认人只看昵称。

### 2026-11-10

- `@bot 帮助`、`@bot 反馈 内容`。
- 主人可以把指定消息发到指定群（`转发到群` / `发给群`）。
- 一条消息里的多张图会拼成一张再交给模型。
- 看图模型超时后，会换默认模型再试一次。

### 2026-11-09

- 聊天里问头像时，桥去拉头像，再让模型看着图回答。
- 消息里的 `@` 会解析成「昵称（QQ 号）」交给模型。
- 同一个群、同一段文字，5 分钟内不发第二遍。

### 2026-11-06

- `@bot 语音！内容`：本机 GPT-SoVITS 合成后以语音发到群里。合成失败会改回文字，并先说一声。

### 2026-10-30

- 群默认封印。解禁咒才闲聊，新拉进来的群也是闭嘴的。主人的任务、撤回、截屏不受封印影响。
- 路人念咒只给联网搜索；关掉 `search` 就变回「这招只听主人的」。
- 回复还没生成完时，同群新来的 `@` 会攒成一轮一起回。

### 2026-10-29

- 回复发出后会再看几秒，群里有新话才决定要不要接。
- 群里一段时间足够热闹，才会考虑插一句。封印群不参加。
- 主人的 agent 任务可以中途收补充说明。

## 这些不要推进公开仓库

`.gitignore` 已经挡了：本机凭据、聊天记忆、反馈、记账、日志、截图和头像、`tmp/` 里的临时脚本。运维备忘和扫码脚本也留在本机，里面有内网地址和口令。
